# Managing Transactions

Learn everything about creating, editing, and organizing your transactions.

## What is a Transaction?

A transaction represents any money movement - either income (money in) or expense (money out).

### Transaction Components

Every transaction has:

- **Amount** - How much money (required)
- **Type** - Income or Expense (required)
- **Category** - How to classify it (required)
- **Date** - When it occurred (defaults to today)
- **Note** - Additional details (optional)

## Adding Transactions

### Scan Receipt (Fastest!)

The easiest way to add an expense:

1. Tap the + button
2. Choose "Scan Receipt"
3. Take a photo of your receipt
4. Wait 2-3 seconds for AI processing
5. Review auto-filled details
6. Tap Save

**Key benefits:**
- Auto-fills merchant, amount, and date
- Receipt image saved automatically
- Works offline - no internet required
- 100% private - all processing on your device

**[Learn more about receipt scanning →](receipt-scanner.md)**

### Manual Entry

For quick manual transactions:

1. Tap the + button
2. Choose "Manual Entry"
3. Enter amount
4. Select Income or Expense
5. Choose category
6. Tap Save

Time: ~5 seconds

### Detailed Add

For more information:

1. Tap the + button
2. Enter amount
3. Select type
4. Choose category
5. Change date if needed
6. Add a note
7. Tap Save

### Tips for Quick Entry

- Use the number pad for fast amount entry
- Default type is usually Expense (most common)
- Default date is today
- Notes are optional - skip if not needed

## Editing Transactions

### Edit Details

To modify a transaction:

1. Tap the transaction in your list
2. Change any field:
   - Amount
   - Type
   - Category
   - Date
   - Note
3. Tap Save

### When to Edit

- Correct mistakes
- Update incomplete information
- Change category
- Fix wrong amount

!!! warning "Edit Carefully"
    Editing changes the transaction permanently. There's no edit history.

## Deleting Transactions

### Swipe to Delete

Quick deletion:

1. Swipe left on transaction
2. Tap Delete button
3. Confirm if prompted

### Delete from Details

Alternative method:

1. Tap transaction to open
2. Find Delete button
3. Confirm deletion

!!! danger "Deletion is Permanent"
    Deleted transactions cannot be recovered. Double-check before deleting.

## Transaction Types

### Income

Money coming in:

- Salary/wages
- Freelance payments
- Gifts received
- Refunds
- Investment returns
- Other income

**Display**: Usually shown in green with + symbol

### Expense

Money going out:

- Purchases
- Bills
- Services
- Subscriptions
- Gifts given
- Other spending

**Display**: Usually shown in red with - symbol

## Transaction List

### Viewing Transactions

Your transaction list shows:

- Most recent at top (default)
- Grouped by date
- Color-coded by category
- Type indicator (income/expense)

### Sorting Options

Sort transactions by:

- Date (newest first)
- Date (oldest first)
- Amount (highest first)
- Amount (lowest first)
- Category

### Filtering

Filter to show only:

- Specific category
- Income only
- Expenses only
- Date range
- Amount range

## Search

### Quick Search

Find transactions fast:

1. Tap search icon
2. Type search term
3. Results appear instantly

### Search By

- Amount (exact or partial)
- Note text
- Category name
- Date

### Search Tips

- Use partial matches
- Search is case-insensitive
- Clear search to see all transactions

## Bulk Operations

### Select Multiple

To work with multiple transactions:

1. Enter selection mode
2. Tap transactions to select
3. Choose action:
   - Delete selected
   - Change category
   - Export selected

### When to Use Bulk

- Cleaning up old data
- Recategorizing multiple items

## Receipt Images

### Viewing Saved Receipts

To view a receipt image:

1. Tap transaction with receipt thumbnail
2. Tap the receipt image to view full-screen
3. Pinch to zoom
4. Share or export if needed

### Managing Receipts

- Receipt images are compressed to save space (~100-500 KB each)
- Sync via iCloud if enabled

- Export transactions to save receipts externally

## Best Practices

### Timing

- **Scan immediately** - Best accuracy when receipt is fresh
- **Add immediately** - Don't wait
- **Daily review** - Check for missed items
- **Weekly cleanup** - Fix any errors

### Accuracy

- **Round if needed** - $4.99 can be $5
- **Be consistent** - Use same categories
- **Add context** - Brief notes help later

### Organization

- **Use categories** - Don't skip this
- **Meaningful notes** - Future you will thank you
- **Regular cleanup** - Delete test entries

## Common Scenarios

### Split Transactions

If you need to split one purchase:

1. Add multiple transactions
2. Use same note for reference
3. Different categories for each part

Example: Grocery store trip
- $50 - Food & Dining - "Groceries"
- $15 - Household - "Cleaning supplies"

### Recurring Transactions

For regular expenses:

1. Add transaction each time
2. Use consistent note
3. Same category each time

!!! tip "Future Feature"
    Recurring transaction automation may be added in future versions.

### Refunds

To record a refund:

**Option 1**: Delete original expense

**Option 2**: Add as income with note "Refund: [original purchase]"

**Option 3**: Edit original to reduce amount

Choose based on your preference.

## Troubleshooting

### Transaction Not Saving

- Check all required fields are filled
- Ensure amount is valid number
- Try restarting the app

### Transaction Disappeared

- Check filters - might be hidden
- Check date range
- Check if accidentally deleted
- Verify iCloud sync status

### Wrong Amount

- Edit the transaction
- Or delete and re-add
- Double-check number pad entry
