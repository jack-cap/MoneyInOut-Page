# Analysis & Reports

Understand your spending patterns with Money In & Out's analysis features.

## Overview

The Analysis view helps you visualize and understand your financial data through charts, summaries, and breakdowns.

## Period Selection

### Available Periods

View your data by:

- **Day** - Single day breakdown
- **Week** - 7-day period
- **Month** - Calendar month
- **Year** - Full year

### Navigating Periods

- **Current** - Tap period name to return to current
- **Previous** - Tap left arrow
- **Next** - Tap right arrow
- **Jump** - Tap date to select specific period

### Period Comparison

Compare periods to see:

- Spending trends
- Seasonal patterns
- Growth or reduction
- Category changes

## Summary Statistics

### Key Metrics

At a glance, see:

- **Total Income** - All money in
- **Total Expenses** - All money out
- **Net Balance** - Income minus expenses
- **Transaction Count** - Number of transactions

### Understanding Net Balance

- **Positive** (green) - Income > Expenses
- **Negative** (red) - Expenses > Income
- **Zero** - Income = Expenses

## Category Breakdown

### Pie Chart

Visual representation showing:

- Each category as a slice
- Size proportional to spending
- Color-coded by category
- Percentage of total

### Category List

Detailed breakdown with:

- Category name and icon
- Total amount spent
- Percentage of total spending
- Number of transactions
- Tap to see category details

### Top Categories

Quickly identify:

- Highest spending categories
- Categories to focus on
- Unexpected high spenders

## Income vs Expense

### Comparison View

See the balance between:

- Total income (green)
- Total expenses (red)
- Net difference

### Trend Analysis

Track over time:

- Are expenses growing?
- Is income stable?
- What's the trend?

## Transaction Details

### Drill Down

### Filter by Category

## Export & Sharing

### Export Data

To export your analysis:

1. Go to Settings or More
2. Select Export
3. Choose format (CSV)
4. Select date range
5. Save or share

### What's Included

Export contains:

- All transactions in range
- Date, amount, type
- Category, notes
- Formatted for spreadsheets

### Use Cases

- Import to Excel/Numbers
- Share with accountant

- Further analysis

## Troubleshooting

### Numbers Don't Match

If totals seem wrong:

- Check date range
- Verify all transactions loaded
- Check for filters applied
- Ensure iCloud sync complete

### Missing Transactions

If transactions don't appear:

- Check period selection
- Verify transaction date
- Check category filters
- Refresh the view

### Chart Not Updating

If chart doesn't refresh:

- Pull to refresh
- Close and reopen app
- Check for app updates
