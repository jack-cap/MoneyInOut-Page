    Common Issues¶

    Most issues can be resolved by:

    1. Restarting the app - Close completely and reopen
    2. Checking for updates - Ensure you have the latest version
    3. Reviewing settings - Verify iCloud sync and other settings
    4. Restarting device - Sometimes needed for sync issues

    Contact Support¶

    Email Support¶

    For issues not covered in documentation:

    Email: MoneyIO@thecapitalyst.com

    Please include:

    • Description of the issue
    • Steps to reproduce
    • Device model (iPhone 14, iPad Pro, etc.)
    • iOS/macOS version
    • App version
    • Screenshots if relevant

    Response Time¶

    We aim to respond within:

    • 24-48 hours for most inquiries
    • Faster for critical issues
    • Slower on weekends/holidays

    Reporting Bugs¶

    Found a bug? Help us fix it:

    What to Include¶

    1. Clear description - What's wrong?
    2. Steps to reproduce - How to trigger the bug?
    3. Expected behavior - What should happen?
    4. Actual behavior - What actually happens?
    5. Device info - Model and OS version
    6. Screenshots - If applicable

    Example Bug Report¶

    Issue: Transaction amounts showing incorrectly

Steps to reproduce:
1. Add transaction with amount $123.45
2. View in transaction list
3. Amount shows as $12.34

Expected: Should show $123.45
Actual: Shows $12.34

Device: iPhone 14 Pro
iOS: 17.1
App version: 1.0.0

    Troubleshooting Guides¶

    Sync Issues¶

    If iCloud sync isn't working:

    1. Check iCloud Drive
    2. Settings → [Your Name] → iCloud
    3. Ensure iCloud Drive is ON

    4. Tap "Saved to iCloud" → Ensure Money In & Out is enabled

    5. Check Internet

    6. Need active connection

    7. Try WiFi if on cellular

    8. Check Storage

    9. Settings → [Your Name] → iCloud
    10. Tap "Manage Account Storage"

    11. Ensure storage available

    12. Toggle Sync

    13. Disable Money In & Out in iCloud
    14. Wait 30 seconds

    15. Re-enable

    16. Restart

    17. Close app completely
    18. Restart device
    19. Reopen app

    Performance Issues¶

    If app is slow or laggy:

    1. Close other apps - Free up memory
    2. Restart app - Fresh start
    3. Restart device - Clear system cache
    4. Check storage - Ensure device has free space
    5. Update iOS - Latest version often faster

    Data Issues¶

    If transactions are missing or wrong:

    1. Check filters - May be hiding transactions
    2. Check date range - Verify period selection
    3. Check sync - Wait for sync to complete
    4. Pull to refresh - Force refresh the list
    5. Check all devices - Verify on another device
